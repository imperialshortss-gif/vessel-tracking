# VesselTrack

Admin-controlled automatic vessel voyage simulation.

## Current version
- React + Vite + TypeScript
- Leaflet + OpenStreetMap map
- Automatic position calculation from departure time, route and speed
- Admin prototype for creating voyages
- Public tracking dashboard foundation

## Next phase
- Supabase PostgreSQL persistence
- Secure admin authentication
- Public tracking IDs
- Server-side simulation state
- Pause/resume/edit controls
- Production hardening and Netlify deployment
